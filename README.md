# 風よわナビ（MVP）

農薬散布や軽作業向けに、風速予報を期間別に可視化するシンプルWebアプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 地点を検索するか、現在地を使う
3. 表示期間（48時間 / 1週間 / 1ヶ月）を選ぶ
4. 風速に応じた判定を確認する

## 判定基準（初期値）

- `<= 2.5 m/s`: 散布向き
- `<= 4.0 m/s`: 軽作業向き
- `> 4.0 m/s`: 注意

## データソース

- 予報: Open-Meteo Forecast API
- 地点検索: Open-Meteo Geocoding API

## 表示期間について

- `48時間`: 1時間ごとの風速を表示
- `1週間`: 1時間ごとの風速を表示
- `1ヶ月`: 日最大風速を表示（Open-Meteo仕様により実際は最大16日分）

## 今後の拡張候補

- 突風（最大瞬間風速）や風向を反映
- 作物・作業ごとの閾値プリセット
- 日次サマリー表示
- PWA対応（ホーム画面追加、オフラインキャッシュ）
