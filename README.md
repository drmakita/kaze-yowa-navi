# kaze-yowa-navi

# 風よわナビ（MVP）

農薬散布や軽作業向けに、風速予報を期間別に可視化するシンプルWebアプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 地点を検索するか、現在地を使う
3. 表示期間（48時間 / 1週間 / 1ヶ月 / 過去48時間）を選ぶ
4. 「平均風速 / 突風」の判定を確認する
5. 精度指標（MAE・判定一致率・モデル重み）を確認する

## 判定基準（初期値）

- `<= 2.5 m/s`: 散布向き
- `<= 4.0 m/s`: 軽作業向き
- `> 4.0 m/s`: 注意

## データソース

- 予報: Open-Meteo Forecast API
- 地点検索: Open-Meteo Geocoding API

## 表示期間について

- `48時間`: 1時間ごとの予測（平均風速 / 突風）を表示
- `1週間`: 1時間ごとの予測（平均風速 / 突風）を表示
- `1ヶ月`: 日最大の予測を表示（Open-Meteo仕様により実際は最大16日分）
- `過去48時間`: 予測と実測の差分をカード表示

## 実測比較（アメダス）

- 最寄り1点ではなく、近傍4観測所の距離加重平均を実測代表値として使用
- 過去2日間の同時刻データで平均絶対誤差（MAE）と2.5m/s閾値の判定一致率を表示
- 「過去48時間」タブで同時刻データを「予測 / 実績 / 差分」のカード表示
- アメダスは国内データのため、日本国外の地点では比較できない場合があります

## 予測改善ロジック

- 複数モデル（`best_match / gfs_seamless / jma_msm`）のアンサンブル
- モデルごとの過去誤差から重みを自動調整（誤差が小さいモデルほど高重み）
- 地点ごとのバイアス補正（過去2日間の予測-実測の平均誤差）
- 標高差ベースの簡易地形補正
- 予測レンジ（モデル間の最小-最大）を各カードに表示
